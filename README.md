# Repurpose AI

Paste a blog post / video transcript / newsletter draft → get a Twitter/X thread, LinkedIn post, Instagram caption, YouTube description, and newsletter blurb, generated by Claude.

Freemium model: 3 free generations per visitor, then $15/month unlimited via Stripe subscription.

## 1. Run it locally

```bash
npm install
cp .env.example .env
```

Edit `.env` and add your `ANTHROPIC_API_KEY` (from https://console.anthropic.com/settings/keys — pay-as-you-go, a few cents per generation). Stripe keys are optional for local testing — without them, "Upgrade" just shows an error instead of opening checkout.

```bash
npm start
```

Open http://localhost:3000.

## 2. Set up payments (Stripe)

You'll need to do this yourself — creating accounts and handling live payment credentials isn't something I can do on your behalf.

1. Create a free account at https://dashboard.stripe.com
2. Products → Add Product → "Repurpose AI Pro", recurring price $15/month → copy the **Price ID** (`price_...`) into `STRIPE_PRICE_ID`
3. Developers → API keys → copy the **Secret key** into `STRIPE_SECRET_KEY`
4. Developers → Webhooks → Add endpoint → URL: `https://yourdomain.com/api/stripe-webhook`, event: `checkout.session.completed` and `customer.subscription.deleted` → copy the **Signing secret** into `STRIPE_WEBHOOK_SECRET`
5. Start in **Test mode** first, use Stripe's test card `4242 4242 4242 4242` to confirm the flow, then switch to live keys when ready.

## 3. Deploy

Cheapest realistic path:
- **Hosting**: Render.com or Railway.app free/low-cost tier (Node app + persistent disk for `data.json`), or Fly.io. Vercel doesn't suit this well because the app needs a persistent filesystem — if you want Vercel, swap the storage for a hosted Postgres (e.g. Supabase free tier) later.
- **Domain**: ~$10-15/year from Namecheap or Cloudflare.
- Set the same environment variables (`ANTHROPIC_API_KEY`, `STRIPE_*`) in your host's dashboard.

## 4. The realistic path to $2000/month

At $15/month, you need **~134 paying subscribers**. Some math to keep you honest: most tools like this convert free→paid at roughly 2-5%, so you'd need on the order of 3,000-6,000 people to actually try the free tool — not just visit the landing page.

Where those users plausibly come from, roughly in order of effort-to-payoff for a solo person:
1. **Build in public on X/Twitter and LinkedIn** — post your own repurposed content (using the tool on your own posts) daily. This is the single highest-leverage channel because the tool's output IS the marketing content.
2. **r/socialmedia, r/marketing, r/SaaS, r/Entrepreneur** — share it as a free tool when you have a working link, not before (no self-promo until you've contributed genuinely).
3. **Product Hunt launch** once the MVP is polished — a decent launch can bring a few hundred visitors in a day.
4. **SEO on long-tail keywords** — "repurpose blog post to twitter thread", "video transcript to linkedin post" etc. Low competition, low volume, but compounds over months.
5. **Directly DM/email 20-30 content creators or small marketing agencies** offering free Pro access in exchange for feedback — a few will convert to paid and refer others.

Realistic timeline: most solo indie tools take **3-6 months** of consistent posting/iteration to reach a few hundred dollars MRR, and 6-12 months to approach $2000 MRR, if the tool actually solves the problem well and you stay consistent with distribution. The code is the easy 20%; distribution is the hard 80%.

## Known limitations to fix before real launch

- Free-tier tracking uses `localStorage`, so it resets if someone clears cookies or uses incognito — fine for MVP, but for a real launch add at least IP-based rate limiting as a backstop.
- No real user accounts (login) — Pro status is tied to a browser-generated anonymous ID stored in localStorage. This is fine to launch with, but if a paying user switches browsers/devices they'll appear unpaid. Adding email-based auth (e.g. magic links) is the natural next step once you have your first paying customers.
